# Helixora frontend

React, TypeScript, and Vite. See the [project README](../README.md) for setup,
analysis assumptions, and the optional Python API.

```sh
npm ci
npm run dev
```

`npm test` runs the analysis and file-parser tests with Node.js 24.
`npm run build` creates `dist/` for GitHub Pages; relative asset paths allow the
app to run under the repository URL.
